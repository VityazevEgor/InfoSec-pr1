# Информационная безопасность: Практическая работа №1 (SAST)

Демонстрационный проект веб-приложения на Python/Flask для исследования методов статического анализа защищённости исходного кода (SAST) с использованием **Semgrep CE** и **Bandit**, а также настройки конвейера непрерывной интеграции (CI/CD) в парадигме **Shift Left**.

---

## Навигация по этапам работы (Git Tags)

Репозиторий размечен контрольными точками (Git Tags), позволяющими мгновенно переключаться между ключевыми этапами выполнения практической работы:

| Git Tag | Описание этапа | Содержимое |
|---|---|---|
| `stage-1-vulnerable` | **Исходное уязвимое состояние** | Демонстрационное веб-приложение, содержащее изолированные уязвимости (SQLi, Command Injection, MD5/SHA-1, eval RCE, Hardcoded Secrets, Debug Mode). |
| `stage-2-fixed` | **Устранение всех уязвимостей** | Полностью исправленный исходный код. Чистый повторный скан Semgrep (`0 findings`). |
| `stage-3-rules-and-ignore` | **Продвинутая конфигурация** | Набор кастомных правил `custom_rules.yml` (сигнатуры + Taint-анализ) и файл исключений `.semgrepignore`. |
| `stage-4-ci-cd` | **CI/CD и Quality Gate** | Пайплайн GitHub Actions `.github/workflows/sast-security-check.yml`, скрипты Quality Gate и автоматическая регистрация Issue при обнаружении дефектов. |

### Команды переключения между этапами:
```bash
# Переключиться на исходное уязвимое приложение (для проверки первичного сканирования)
git checkout stage-1-vulnerable

# Переключиться на исправленный код (0 findings)
git checkout stage-2-fixed

# Переключиться на этап с кастомными правилами Semgrep
git checkout stage-3-rules-and-ignore

# Вернуться к финальному состоянию с настроенным CI/CD
git checkout main
```

## Запуск приложения и сканеров

### 1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 2. Запуск приложения:
```bash
python app/main.py
```

### 3. Локальный статический анализ:
```bash
# Базовое сканирование Semgrep
semgrep scan --config auto app/

# Сканирование кастомным набором правил
semgrep scan --config custom_rules.yml app/

# Анализ с помощью Bandit
bandit -r app/
```
